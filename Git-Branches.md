# What is a Branch?
Ans: A branch is a version of some project which shows different features. For exampple a project can have multiple branches including the main branch. The main branch is the branch which shows the main version of the project and the other branches are like other possible variants of the same project.

# What is a pull request 
A pull request is a proposal to merge code changes in features into main git. 

Aside from merging code, a pull request does a set of works
 - Reviewing code, Catching errors, Discuss issues and approve 


# Why do not we directly code on main?
We do not directly code on main because we want to keep the main branch safe. Below are some more reasons:-
- Risk of broken production
- Loss of rollback safely 
- No code review 
- Team collisions
